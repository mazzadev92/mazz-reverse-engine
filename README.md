## En quelques mots : Qu'est-ce que MazzRE ?

**MazzRE** est la station de travail de retro-ingenierie et d'exploration de programmes creee au sein de **MAZZ AENGENIUM**.

Avez-vous deja demonte une vieille montre, une console de jeu ou une voiture telecommandee pour decouvrir ses circuits, ses roues dentees et comprendre son fonctionnement interne ?

Dans le monde informatique, les createurs de logiciels et de jeux emballent l'integralite de leur travail dans des fichiers executables scelles (les fameux fichiers `.exe`). **MazzRE agit comme un microscope numerique de haute precision** : il vous permet d'ouvrir ce fichier hermetique, de regarder sous le capot et d'analyser tous ses secrets d'ingenierie.

---

## A quoi ca sert ? Les 5 missions du detective logiciel

1. **Explorer les secrets des jeux video**  
   Comprenez comment sont organises les modeles 3D, les textures, les cartes de jeu et les fichiers de sauvegarde dans les jeux developpes avec Unreal Engine. MazzRE sait deballer les archives de donnees (fichiers `.pak`) et lire les sauvegardes (`.gvas`) pour etudier les methodes des studios de jeu video.

2. **Chasser les virus et les pieges caches**  
   Avant d'executer un fichier inconnu telecharge sur Internet, MazzRE vous permet de l'inspecter a froid sans aucun danger. Revelez s'il cherche a espionner votre machine, lisez les adresses web auxquelles il souhaite se connecter et certifiez sa proprete.

3. **Dissequer les applications modernes**  
   La majorite des logiciels du quotidien (comme Discord ou Spotify) sont concus avec des technologies web hybrides (Electron, WebAssembly). MazzRE deballe ces paquets pour vous reveler le code source JavaScript et les modules natifs internes.

4. **Comprendre les modeles d'intelligence artificielle**  
   Les fichiers neuronaux (fichiers `.gguf` ou SafeTensors) constituent d'immenses collections de tenseurs mathematiques. MazzRE analyse leur structure interne, calcule l'empreinte memoire requise et quantifie la repartition des couches de neurones.

5. **Reconstruire un logiciel neuf et legal (Methode Clean-Room)**  
   C'est la pratique des plus grands architectes logiciels : analyser le comportement d'un programme existant, documenter sa specification fonctionnelle, puis reecrire un logiciel moderne, rapide et 100 % legal sans jamais copier une seule ligne de code d'origine.

## Utiliser MazzRE en 3 Etapes Simples

1. **Ouvrez MazzRE** et glissez-deposez n'importe quel fichier executable, jeu video ou archive dans la fenetre.
2. **Choisissez un mode d'analyse** : triage rapide, inspection d'archive Unreal, audit d'application web ou examen de tenseurs neuronaux.
3. **Consultez le rapport visuel** : visualisez l'architecture, les composants et les flux en toute simplicite.

## Architecture & Capacites Techniques

- **Cœur Haute Performance** : C++20 optimise, interface Qt6 ultra-reactive.
- **Protocole MCP (Model Context Protocol)** : Expose l'ensemble des analyseurs binaires sous forme d'outils standardises pour agents d'intelligence artificielle (Claude Code, MAZZ Code, Antigravity).
- **Moteurs d'analyse integres** : Triage PE/ELF, signatures DIE/TrID, extraction FLOSS, deballage Unreal Engine (PAK/GVAS), extraction Electron/WASM, parsing EVM bytecode et audit SafeTensors/GGUF.
